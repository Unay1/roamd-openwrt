# roamd-openwrt

Неофициальная downstream-сборка пакетов **roamd** для OpenWrt с собственным репозиторием APK/IPK и установщиком.

## Назначение

Цель проекта — собирать и публиковать оригинальные пакеты roamd из открытого исходного кода, но размещать пакеты и индексы в собственном репозитории. Это убирает зависимость установки и обновления от стороннего feed Ground-Zerro.

Исходный проект: [Ground-Zerro/roamd](https://github.com/Ground-Zerro/roamd).  
Лицензия исходного проекта: Apache-2.0.  
Проверенная исходная ревизия: `d4f71296ae057e29448c8a371b720811b744faa2` (`roamd 1.2.0-r2`).

## Целевое устройство первой сборки

- Netis NX31
- OpenWrt 25.12.6
- target `mediatek/filogic`
- package architecture `aarch64_cortex-a53`
- пакетный менеджер APK

## Принципы проекта

1. Не изменять алгоритмы roamd без необходимости.
2. Сохранять лицензию, авторские уведомления и указывать изменения downstream.
3. Не использовать приватные ключи upstream — выпускать собственные подписи.
4. Не удалять автоматически конфликтующие пакеты `usteer` и `dawn`.
5. Проверять пакеты на целевой версии OpenWrt до публикации.
