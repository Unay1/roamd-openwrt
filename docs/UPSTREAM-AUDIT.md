# Аудит исходного проекта roamd

Дата аудита: 2026-11-14.

## Исходный проект

- Репозиторий: https://github.com/Ground-Zerro/roamd
- Проверенная ревизия: `d4f71296ae057e29448c8a371b720811b744faa2`
- Коммит: `roamd 1.2.0-r2`, 2026-09-24.
- Лицензия: Apache-2.0.

Исходный проект содержит демон на C, пакеты LuCI и сборочную/публикационную систему:

| Пакет | Версия в проверенной ревизии | Назначение |
|---|---:|---|
| `roamd` | 1.2.0-r2 | демон, init, UCI-конфигурация, RPC/ACL и логика управления |
| `luci-app-roamd` | 1.2.0-r1 | интерфейс LuCI |
| `luci-i18n-roamd-ru` | 1.2.0-r1 | русский перевод |

Сборка выполняется OpenWrt SDK. Для OpenWrt 25.12 создаются APK v3 и индекс `packages.adb`; для 23.05/24.10 — IPK и индексы opkg. В исходном проекте предусмотрены подписи индексов: usign для старых веток и RSA для APK.

## Что важно для нашей сборки

1. Не переписываем демон и интерфейс. Берём исходный код с сохранением лицензии и авторских уведомлений; собственные изменения отмечаем отдельно.
2. Не используем чужие закрытые ключи. Создадим собственную пару ключей подписи и будем хранить приватный ключ только в GitHub Actions Secrets.
3. Не используем старый установщик без изменений: он указывает на репозиторий Ground-Zerro. Установщик нашей сборки должен обращаться только к релизам/фиду `Unay1/roamd-openwrt`.
4. Не удаляем автоматически конфликтующие пакеты. Оригинальный установщик проверяет наличие `usteer` и `dawn` и прекращает установку; такую защиту сохраним.
5. Сначала собираем и проверяем APK для OpenWrt 25.12.6, затем расширяем матрицу архитектур и веток.

## Целевое устройство для первой сборки

Netis NX31:

- OpenWrt: 25.12.6;
- target: `mediatek/filogic`;
- package architecture: `aarch64_cortex-a53`.

В таблице архитектур upstream для 25.12 архитектура `aarch64_cortex-a53` сопоставлена SDK `bcm27xx/bcm2710`; отдельной строки `mediatek/filogic` там нет. При этом официальный SDK OpenWrt 25.12.6 для `mediatek/filogic` опубликован. Для первой контрольной сборки используем именно SDK целевого семейства роутера, чтобы проверить сборку на соответствующем target, а не полагаться только на совпадение package architecture.

## Замечания к upstream

- Документация upstream указывает SDK 25.12.5, тогда как на тестовом устройстве установлена OpenWrt 25.12.6. Для нашей первой сборки берём SDK 25.12.6.
- В workflow upstream значение версии при ручном запуске по умолчанию указано как `1.2.0-r1`, тогда как Makefile демона содержит `1.2.0-r2`. Наш workflow должен получать версии из Makefile или проверять их согласованность, а не хранить вторую независимую константу.
- Документация upstream содержит примечание о передаче дальнейшего развития проекту Freenetic. Однако в проверенном публичном репозитории `unisequence/freenetic` исходники roamd не обнаружены. Поэтому для этой сборки фиксируем конкретную проверенную ревизию Ground-Zerro и не предполагаем, что другой репозиторий является актуальным зеркалом roamd.

## План работ

1. Импортировать исходники демона, LuCI и русский перевод с фиксацией upstream commit.
2. Подготовить SDK-сборку OpenWrt 25.12.6 для `mediatek/filogic`.
3. Добавить CI-проверки, сборку трёх пакетов и проверку их метаданных/зависимостей.
4. Настроить собственную подпись APK-репозитория и публикацию `packages.adb`.
5. Написать безопасный установщик/обновлятор для нашего репозитория.
6. Проверить установку на тестовом роутере только после резервной копии и согласования конфликта с уже установленным менеджером роуминга.
